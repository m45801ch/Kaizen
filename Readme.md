# 改善提案生成器（KAIZEN V4 · AI 版）說明檔

## 一、網站簡介

本工具是一個「改善提案表」的線上生成與排版工具。使用者可自行輸入改善前、改善後與預期效益的內容、上傳現場照片，並可透過 AI 一鍵產生正式措辭，最後直接列印或匯出為 A4 PDF。

所有資料（設定、表單內容、照片）皆只儲存在你自己的瀏覽器中，不會上傳到任何第三方伺服器。

## 二、使用環境

- **線上直接使用**：https://m45801ch.github.io/Kaizen/v4/ （V4 多模板版，GitHub Pages 自動部署，push 後自動更新）。
- 建議使用 Chrome、Edge 或 Firefox 等現代瀏覽器開啟。
- 也可本機架設伺服器開啟 `v4/` 目錄使用（ES Modules 多檔，需 HTTP 伺服器，如 `python -m http.server`）。
- 首次使用請在左側「API 設定」輸入你的 AI API Key（Google Gemini 或 OpenAI）。

## 三、左側面板功能

### 1. API 設定
- **供應商切換**：可切換 Google Gemini 或 OpenAI 兩種 AI 服務。
- **API Key**：貼上你的 API Key（僅存於本機瀏覽器）。輸入後系統會自動重新載入可用模型。
  - 按「顯示／隱藏」可切換密碼顯示狀態。
- **模型選擇**：下拉選擇要使用的 AI 模型；按「⟳」可重新載入全部可用模型。
- 此面板可點標題列收合／展開。

### 2. AI 一鍵生成
- 於右側表單或左側「正式措辭描述」任一處輸入改善前／改善後內容。
- 勾選「覆蓋已填欄位」時，AI 生成結果會覆蓋原本已填的內容；未勾選時只填空白欄位。
- 按下「點我 · 自動填寫＋口語化」後，會同時：
  1. 產生正式措辭並填入右側表單（改善前、改善後、預期效益）。
  2. 產生正式化的一段描述，填入左側「正式措辭描述」欄位。

### 3. 正式措辭描述（可輸入／複製）
- 改善前（問題描述）與改善後（對策描述）兩個文字框。
- 每個文字框下方有「複製」按鈕，可一鍵複製內容，方便貼入公司表格。

## 四、右側表單功能

### 1. 工具列
| 按鈕 | 功能 |
|------|------|
| A4 直向／A4 橫向 | 切換紙張方向，預覽與列印會同步改變 |
| 列印 / 匯出 PDF | 開啟瀏覽器列印視窗，可另存為 PDF |
| 清空重置 | 清除所有欄位與照片（需確認） |

### 2. 文件標題
- 頁面上方的「改善提案表」可直接點擊輸入修改為自訂標題（例如「維修保養改善提案表」）。
- 清空內容時會自動回復為預設標題；關閉網頁後再次開啟仍會保留。

### 3. 公司 LOGO
- LOGO 左下方的「更換LOGO」按鈕可上傳自己的圖檔取代內建 LOGO，會自動壓縮至寬度 360px 內並記憶。
- 「回復」按鈕可還原為內建 LOGO。
- 更換後的 LOGO 會同步顯示於列印／PDF 輸出中。

### 4. 改善主題
- 於「改善主題：」欄位輸入提案名稱（例如「調質 server 電腦不斷電系統改善」）。

### 5. 改善前／改善後區塊
- 每個區塊可上傳**多張照片**（點「＋ 上傳照片」或直接拖曳圖片到區域內）。
- 照片排列規則：
  - **第一張（主圖）**：佔滿整行，依調整後的比例完整顯示（不裁切）。
  - **其餘圖片**：以縮圖形式排列在主圖下方，依調整後的寬度每行自動排列（不裁切）。
- **主圖寬度／縮圖寬度**滑桿：可各自調整圖片顯示大小（主圖 30%–100%，縮圖 10%–100%），設定會自動記憶。
- 每張照片右上角在滑鼠移過時會出現 ✕，點擊可移除照片。

### 6. 改善內容（分析列點）
- 每個區塊下方為「現況說明／改善對策」編輯區。
- 輸入以「標題：內容」或列點格式撰寫的文字，上方會自動排版為彩色列點預覽。
- 點一下預覽文字即可切回編輯；AI 一鍵生成時會自動填入。

### 7. 預期效益
- 三個欄位，可各別輸入預期成果（例如「減少滑倒事故 50%」「縮短搬運時間 30%」）。

## 五、直向／橫向版面差異

- **A4 直向（預設）**：改善前後並排於上方，「預期效益」位於下方。
- **A4 橫向**：
  - 表單加寬，改善前後位於左側，「預期效益」移到**右側**直排顯示。
  - 版面空白區域（上下左右留白）會自動縮小，充分利用橫式空間。
  - 若視窗較窄，會自動回復為上下排列。

## 六、列印與匯出 PDF

1. 調整好 A4 直向／橫向與圖片大小。
2. 按下「列印 / 匯出 PDF」。
3. 在瀏覽器的列印視窗中選擇「另存為 PDF」即可。
   - 建議：紙張大小選 A4，邊界設為「無」或「預設」，並開啟「背景圖形」以保留底色與標題色彩。
4. PDF 輸出版面與畫面上的表單一致（含照片排列與大小）。

## 七、資料儲存說明

| 內容 | 儲存位置 |
|------|----------|
| API Key、供應商、模型、版面設定、表單文字、標題、圖片大小、公司 LOGO | 瀏覽器 localStorage |
| 上傳的照片 | 瀏覽器 IndexedDB |

- 清除瀏覽器資料（或使用無痕／私密視窗）會清空上述資料，請自行備份 API Key。
- 照片限制：每邊（改善前／改善後）最多 10 張、單張 15MB 以內。

## 八、常見問題

**Q1：AI 沒有回應？**
請確認左上方 API 設定有輸入正確的 API Key，且模型已成功載入；可先按「⟳」重新載入模型。

**Q2：照片上傳失敗？**
請確認單張圖片小於 15MB、為常見圖片格式（JPG／PNG 等），且每邊不超過 10 張。

**Q3：列印出來沒有顏色／排版跑掉？**
在瀏覽器列印視窗中勾選「背景圖形」；紙張大小選擇 A4，邊界選擇「預設」或「無」。

**Q4：重新開啟網頁後資料還在嗎？**
表單文字、標題、設定、LOGO 與照片會保留；只有清除瀏覽器資料時才會消失。

## 九、更新與部署

- 本專案透過 GitHub Pages 自動部署，任何變更只要 `git push` 到 `main` 分支，約 1–2 分鐘後線上網址即會更新。
- `index.html` 為單一自包含檔案（CSS／JS 全內嵌、LOGO 以 base64 內嵌），可直接開啟使用，亦可任意移植到其他靜態主機。
